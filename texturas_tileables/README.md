# Texturas tileables

Aquí van las texturas del **papel base** (arroz, kraft, acuarela, rayado, cuadrícula...).

Cada una se analizará para identificar el tipo de papel y se convertirá en tileable:
sin costuras, sin degradados de luz y, en papeles con líneas o cuadrícula,
con el patrón coincidiendo exactamente en los bordes.
