# Imperfecciones

Aquí va **todo** lo que se superpone al papel: óxido de clip, relieves de escritura,
café, hongos, salpicaduras, humedad, quemaduras, etc.

Cada imagen se analizará según su naturaleza:
- Algunas se usan casi tal cual (p. ej. un aro de café).
- Otras se descomponen en elementos sueltos (gotas, esporas, motas) para repartirlos por el papel.
- Cada una se coloca donde ocurre en la vida real (p. ej. el óxido de clip en los bordes, nunca en el centro).
